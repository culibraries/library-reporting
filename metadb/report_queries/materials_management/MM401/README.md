# Materials Management: Gemmill Claimed Returned Report

## Purpose
This report returns a list of all items marked 'Claimed returned' across the Engingeering, Math and Physics Library locations.
## Parameters
Searches the Gemmill Engingeering, Math and Physics Library location for items that are currently marked "Claimed returned." Provides the claimed date, item barcode, item location, call number, copy, volume, claimed returned note, loan ID, user name, user email, and user ID.
