# Materials Management: Music Claimed Returned Report

## Purpose
This report returns a list of all items currently marked 'Claimed returned' across the Music Library.
## Parameters
Searches the Music Library location for items that are currently marked "Claimed returned." Provides the claimed date, item barcode, item location, call number, copy, volume, claimed returned note, loan ID, user name, user email, and user ID.
