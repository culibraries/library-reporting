# Materials Management: Norlin Claimed Returned Report 

## Purpose
This report returns a list of all items currently marked 'Claimed returned' across Norlin Library, PASCAL offsite storage, and Engineering (while Gemmill collection still housed in NorBase).
## Parameters
Searches the Norlin Library, PASCAL, and Engineering location for items that are currently marked "Claimed returned." Provides the loan ID, claimed date, item barcode, item location, call number, copy, volume, claimed returned note, user ID, user name, and user email.
