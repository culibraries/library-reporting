# Materials Management: Business Claimed Returned Report

## Purpose
This report returns a list of all items currently marked 'Claimed returned' across the Business Library.
## Parameters
Searches the Business Library for items that are currently marked "Claimed returned." Provides the claimed date, item barcode, item location, call number, copy, volume, claimed returned note, loan ID, user name, user email, and user ID.
